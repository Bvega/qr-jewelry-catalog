# MVP Scope — QR Jewelry Catalog

## Business Goal

Help the seller present jewelry more professionally for Facebook Marketplace buyers by giving each item a clean mobile-first product view and eventually QR/shareable access.

## Primary User

The seller.

## Buyer Experience

The buyer should be able to:

1. Open a product link or QR code.
2. View jewelry photos.
3. Read item name, price, and short description.
4. See whether the item is available, reserved, or sold.
5. Browse related available items.

## Seller Experience

The seller should eventually be able to:

1. Add a jewelry item.
2. Add one or more photos.
3. Add price and short description.
4. Set availability status.
5. Generate or share a product link.

## Lean MVP Feature List

### Phase 1 MVP Features

- Mobile-first catalog homepage
- Static product cards
- Static product detail page
- Sample jewelry data file
- Availability labels
- Elegant visual layout

### Later Features

- QR generation
- Add/edit item form
- Local storage or lightweight database
- Admin-only seller view
- Search and filters
- Category grouping
- Public share links

## Out of Scope for MVP

- payment processing
- shipping workflows
- user accounts
- customer login
- complex inventory system
- marketplace integrations
