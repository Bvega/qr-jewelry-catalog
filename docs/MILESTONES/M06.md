# 5. APPROVED PERMANENT URL CONTRACT

## 5.1 Canonical route

The permanent Find URL format for the static MVP is:

```text
find.html?id={publicId}
```

Examples:

```text
find.html?id=BU-0001
find.html?id=BU-0002
find.html?id=BU-0003
find.html?id=BU-0004
find.html?id=BU-0005
```

Rules:

- `publicId` is the permanent routing identifier.
- Generated canonical URLs must use the exact registered `publicId`.
- Public IDs must not be lowercased, recycled, or transformed.
- The URL must work under local static serving, repository subpaths, and GitHub Pages project hosting.
- Build the absolute URL from the current document location.
- Do not hardcode a domain, repository name, or localhost origin.
- Remove unrelated existing query parameters and hashes when generating the permalink.
- URL-encode query values using browser-native URL APIs.

## 5.2 Slug alias

The permanent detail page may also resolve:

```text
find.html?slug={registered-slug}
```

Rules:

- only exact registered slugs resolve;
- unknown slugs use the existing branded not-found state;
- slug aliases must set the canonical link to the public-ID permalink;
- generated public links, share links, reservation links, and QR payloads must use the public-ID permalink, not the slug alias.

## 5.3 Legacy route

The following must continue to work:

```text
item.html?id=N
```

Requirements:

- all five legacy routes resolve the correct normalized Find;
- legacy numeric identifiers remain unchanged;
- legacy pages render the same approved Find Details experience;
- no forced redirect is required;
- legacy pages set the canonical link to the public-ID permalink;
- legacy pages use the permanent public-ID URL for new Share, Copy Link, Reserve by Message, and QR actions;
- existing already-distributed QR codes remain functional.

## 5.4 Route ownership

M06 owns only:

```text
find.html?id={publicId}
find.html?slug={slug}
item.html?id={legacyId}
```

Do not implement clean-path formats such as `/find/BU-0001`; those require hosting rewrite support and are not approved for the current static GitHub Pages architecture.

```text

```

- use an accessible live region for status;
- do not silently fail;
